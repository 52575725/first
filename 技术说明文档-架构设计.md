# PPT Master 微课视频生成系统 - 架构设计

## 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                      输入层 (Input Layer)                    │
│  PPT / DOCX / PDF / URL / Markdown                          │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│                   解析层 (Parse Layer)                       │
│  • source_to_md (文档转Markdown)                            │
│  • content_analyzer (内容结构分析)                          │
│  • 知识点提取 • 教学节奏分析                                 │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│                   生成层 (Generate Layer)                    │
│  • Strategist (策略规划)                                     │
│  • Executor (SVG生成)                                        │
│  • notes_to_audio (语音合成)                                │
│  • audio_optimizer (缓存优化)                               │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│                   编辑层 (Edit Layer)                        │
│  • finalize_svg (SVG后处理)                                 │
│  • subtitle_generator (字幕生成)                            │
│  • 时间轴对齐 • 视觉增强                                     │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│                   输出层 (Output Layer)                      │
│  • svg_to_pptx (PPTX导出)                                   │
│  • pptx_to_video (视频导出)                                 │
│  • MP4 / SRT / PPTX                                         │
└─────────────────────────────────────────────────────────────┘
```

## 核心模块

### 1. 内容解析模块 (content_analyzer.py)

**功能**：分析PPT内容结构和教学节奏

**输入**：`notes/*.md` (讲解脚本)  
**输出**：内容密度、停顿建议、关键知识点

**核心算法**：
```python
content_density = (text_length / 500 + bullet_points / 10) / 2
recommended_pause = base_pause + chart_bonus + density_bonus
```

### 2. 音频生成模块 (notes_to_audio.py + audio_optimizer.py)

**功能**：生成讲解音频，支持缓存和并行处理

**支持的TTS提供商**：
- edge-tts (默认，免费)
- ElevenLabs (高质量)
- MiniMax (国内)
- Qwen / CosyVoice (阿里云)

**优化特性**：
- MD5缓存避免重复生成
- asyncio并行处理
- 音频后处理（归一化、淡入淡出）

### 3. 视频导出模块 (pptx_to_video.py)

**功能**：将SVG幻灯片和音频合成为MP4视频

**工作流程**：
```
SVG → PNG (cairosvg/Inkscape)
PNG + Audio → MP4片段 (ffmpeg)
MP4片段 → 完整视频 (ffmpeg concat)
可选：添加BGM (ffmpeg filter_complex)
```

**支持参数**：
- 分辨率：720p / 1080p / 4K
- 编码器：H.264 / H.265
- 帧率：30fps / 60fps

### 4. 字幕生成模块 (subtitle_generator.py)

**功能**：生成SRT格式字幕

**时间轴计算**：
```python
start_time = sum(previous_durations)
end_time = start_time + current_audio_duration
```

**输出格式**：
```srt
1
00:00:00,000 --> 00:00:05,500
欢迎来到本节课程
```

## 数据流

```
源文档 → Markdown → 讲解脚本 → 音频文件
                              ↓
SVG幻灯片 → PNG图片 ──────────→ MP4视频
                              ↓
                          字幕文件
```

## 技术栈

**核心依赖**：
- Python 3.8+
- ffmpeg / ffprobe
- edge-tts (默认TTS)
- Pillow / cairosvg (图像处理)

**可选依赖**：
- ElevenLabs SDK (高质量TTS)
- Whisper (精确字幕)
- GPU加速 (NVENC)

## 性能优化

### 并行处理
```python
# 音频生成并行化
async def generate_all():
    tasks = [generate_audio(note) for note in notes]
    await asyncio.gather(*tasks)
```

### 缓存机制
```python
# MD5缓存键
cache_key = md5(f"{provider}|{voice}|{rate}|{text}")
if cached := get_cache(cache_key):
    return cached
```

### 增量更新
```python
# 只重新生成修改的页面
changed = [i for i, svg in enumerate(svgs) 
           if svg.mtime > last_build_time]
```

## 扩展性

### 添加新的TTS提供商

1. 在 `tts_backends/` 创建 `backend_xxx.py`
2. 实现统一接口：
```python
def generate(text: str, output: Path, **kwargs) -> None
def list_voices() -> List[Voice]
```
3. 在 `notes_to_audio.py` 注册

### 添加视频特效

1. 在 `pptx_to_video.py` 添加 ffmpeg filter
2. 示例：添加淡入淡出
```python
filter_complex = "fade=in:0:30,fade=out:st={duration-1}:d=1"
```

## 质量保证

### 自动化测试
- 单元测试：各模块独立测试
- 集成测试：端到端视频生成
- 性能测试：大规模项目压测

### 错误处理
- ffmpeg失败：回退到低分辨率
- TTS失败：切换到备用提供商
- 缓存损坏：自动清理重新生成
