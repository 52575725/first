微课视频一键生成系统 — 技术说明文档

一、系统概述

本系统实现从教案/PPT到微课视频的端到端自动化生成，输入一份 PPTX 文件，自动完成内容解析、AI语音合成、画面编排与音视频同步输出。

一键运行命令： bash python run.py <PPTX路径> [--voice 音色] [--rate 语速]

二、系统架构

输入 PPTX │ ▼ [Step 1] PPT 内容解析 ppt_to_md.py (python-pptx) │ 提取文字、知识点、Speaker Notes ▼ [Step 2] AI 语音合成 notes_to_audio.py (edge-tts / 云端TTS) │ 每页生成独立 MP3，支持语速/语调调节 ▼ [Step 3] 幻灯片截图导出 PowerPoint COM (comtypes) │ 1920×1080 高清 PNG，保留原始排版 ▼ [Step 4] 画面动效生成 ffmpeg zoompan + fade │ Ken Burns 缓动 + 淡入淡出转场 ▼ [Step 5] 音视频拼接 ffmpeg concat │ 按音频时长精确对齐每页画面 ▼ [Step 6] 字幕烧录 ffmpeg subtitles (libass) │ SRT 字幕与语音严格同步 ▼ 输出 MP4 微课视频

三、各模块技术方案

3.1 教案/PPT 智能解析（内容还原度）

  • 工具：python-pptx 解析 PPTX XML 结构
  • 提取内容：
  • 每页文字内容（标题、正文、要点）
  • 内嵌 Speaker Notes（教师备课旁白脚本）
  • 图片资源（保留原始位置信息）
  • 知识点结构化：按页面顺序保留教学节奏，Notes 作为讲解脚本直接驱动语音合成
  • 内容还原度保障：截图使用 PowerPoint COM 原生渲染，像素级还原原始排版

3.2 AI 语音合成

  • 默认引擎：Microsoft Edge TTS（edge-tts）
  • 无需 API Key，本地可运行
  • 支持 zh-CN / zh-TW / en-US 等多语言
  • 推荐音色： | 场景 | 音色 | |------|------| | 商业/财报 | zh-CN-YunjianNeural（男，沉稳）| | 通用教学 | zh-CN-XiaoxiaoNeural（女，清晰）⭐ | | 发布会 | zh-CN-YunyangNeural（男，播报感）|
  • 语速调节：--rate 参数，范围 -50% ~ +50%，默认 +0%
  • 可扩展云端引擎：ElevenLabs / MiniMax / Qwen TTS（高质量克隆音色）

3.3 画面自动编排与视觉效果

每页幻灯片应用 Ken Burns 动效，6种模式循环：

模式 效果
中心放大 zoom 1.0 → 1.08，居中
中心缩小 zoom 1.08 → 1.0，居中
放大+左上平移 zoom in，镜头向左上移动
放大+右下平移 zoom in，镜头向右下移动
缩小+左下平移 zoom out，镜头向左下移动
缩小+右上平移 zoom out，镜头向右上移动

转场：每页首尾各 0.5 秒淡入淡出，避免硬切。

ffmpeg 核心滤镜： scale=3840:2160, zoompan=z='min(z0+(z1-z0)*on/N, zmax)':x='...':y='...':d=N:s=1920x1080:fps=25, fade=t=in:st=0:d=0.5, fade=t=out:st=T-0.5:d=0.5

3.4 音视频对齐方案

  • 帧级精确对齐：每页视频时长 = 对应音频时长（由 ffprobe 精确读取，精度 ms 级）
  • 字幕同步：SRT 时间戳累加各页音频时长，误差 < 1 帧（40ms@25fps）
  • 自动翻页：PPTX 版本中 advTm 属性设为音频时长，支持 PowerPoint 录制模式播放

四、依赖环境

```bash pip install python-pptx edge-tts comtypes

ffmpeg 需单独安装并加入 PATH

```

依赖 版本 用途
python-pptx 1.0+ PPT 解析
edge-tts 7.x 语音合成
comtypes 1.x PowerPoint COM（Windows）
ffmpeg 6.x+ 视频编码/合成/字幕

五、输出规格

参数 值
分辨率 1920 × 1080（1080p）
帧率 25 fps
视频编码 H.264（libx264，CRF 20）
音频编码 AAC 128kbps
字幕 内嵌烧录，微软雅黑 18pt，白字黑边

六、创新点

  1. 零人工干预：从 PPTX 到 MP4 全程自动，无需手动录制
  2. Speaker Notes 驱动：直接复用教师备课旁白作为讲解脚本，内容还原度高
  3. 动态画面：Ken Burns 动效让静态幻灯片具有镜头语言，视觉体验接近真实录课
  4. 多引擎扩展：TTS 引擎可无缝切换至云端高质量音色（ElevenLabs/MiniMax）
  5. 音视频严格同步：基于音频实际时长驱动视频时长，无固定时间假设
